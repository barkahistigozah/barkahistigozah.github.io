Astro cocok untuk website portfolio karena halaman statis bisa dibuat cepat, ringan, dan tetap fleksibel.

## Kenapa MDX

MDX membuat artikel dan detail project terasa seperti dokumen biasa, tetapi masih bisa memakai komponen saat diperlukan.

## Kenapa Tailwind

Tailwind membantu menjaga styling tetap dekat dengan markup. Untuk project kecil sampai menengah, ini mempercepat iterasi desain.

```ts
const stack = ['Astro', 'MDX', 'Tailwind', 'React'];
```

Struktur seperti ini membuat portfolio mudah diisi ulang tanpa perlu menulis ulang desain.

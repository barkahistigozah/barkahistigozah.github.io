## Ringkasan

Personal Portfolio Website adalah website responsif untuk menampilkan profil profesional, project pilihan, artikel teknis, GitHub, dan jalur kontak dalam format yang ringkas dan ramah recruiter.

## Peran

Saya membangun website ini terutama dengan Astro 6, TypeScript, MDX, Tailwind CSS 4, GSAP, Three.js, dan Bun. React 19 hanya untuk filter project interaktif yang dimuat sebagai island melalui integrasi Astro. Saya juga menangani struktur halaman, layout responsif, content collection, metadata SEO, dan deployment statis.

## Problem yang Diselesaikan

Portfolio perlu mudah diperbarui tanpa mencampur isi project dengan komponen UI. Content collection Astro dan MDX memisahkan data dari tampilan, sehingga project dan artikel baru dapat ditambahkan tanpa mengubah alur rendering utama.

## Impact

- Profil, project, artikel, GitHub, dan kontak tersaji dalam satu website.
- Project dan artikel dapat diperbarui melalui MDX.
- Tampilan responsif mendukung mobile dan desktop.
- Metadata SEO, sitemap, dan build statis siap untuk GitHub Pages.

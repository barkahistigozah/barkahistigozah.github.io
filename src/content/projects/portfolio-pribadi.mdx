## Ringkasan

Portfolio Pribadi adalah website personal untuk menampilkan identitas profesional, project pilihan, artikel teknis, dan jalur kontak dalam satu tempat yang ringan dan mudah dirawat.

## Peran

Saya membangun struktur halaman, layout responsif, sistem konten berbasis MDX, dan visual portfolio yang modern. Konten project dan artikel dibuat terpisah agar mudah diperbarui tanpa mengubah banyak komponen UI.

## Problem yang Diselesaikan

Portfolio sering menjadi sulit dirawat ketika semua data ditulis langsung di halaman. Project ini memisahkan data ke content collection, sehingga menambah project baru cukup dengan membuat file MDX.

## Impact

- Struktur siap untuk GitHub Pages.
- Project dan artikel bisa ditulis memakai MDX.
- Desain responsif untuk mobile dan desktop.
- Metadata SEO, sitemap, dan struktur halaman sudah siap untuk publikasi.
